# v0.6.0 — Historical Validation

## Goal

Evaluate the current strategy and risk behavior over completed market history without waiting months for daily paper runs.

## Delivered

- Historical simulator for BTC, ETH and SOL with selectable start date.
- **Test run (+1 day)** advances exactly one completed daily candle.
- **Run to latest** evaluates the full selected period in one action.
- BUY proposals pass through the same deterministic `RiskEngine` and position-sizing engine as paper trading, using an isolated simulated portfolio state.
- Simulated execution includes the configured 0.25% fee and 0.10% slippage.
- Results include portfolio value, return, equal-weight BTC/ETH/SOL buy-and-hold benchmark, maximum drawdown, completed trades, win rate, average realized trade P/L, total fees and open positions.
- Dashboard renders an equity/benchmark curve, latest daily decisions and a simulated trade ledger.
- `/api/simulation/step?startDate=YYYY-MM-DD` advances one day.
- `/api/simulation/run?startDate=YYYY-MM-DD` resets and runs through the latest completed day.
- nginx forwards dashboard `/api/` requests to the backend in Docker Compose.

## Proof

`HistoricalSimulationEndToEndTest` starts the Spring application with deterministic BTC/ETH/SOL history, advances two individual days, proves three BUY signals execute through risk sizing, runs the full range, proves three positions later exit, verifies the equity curve and fee metrics, and confirms the persistent paper ledger remains untouched.

The complete backend test suite and Angular production build pass. A real Kraken smoke test through `http://localhost:4200` also advances a selected period to the latest completed candle and returns the chart, metrics and ledger through the nginx proxy.

## Release smoke sample

For the completed period from 2026-06-01 through 2026-08-29, the simulator processed 90 days and reported:

- strategy return: +3.92%
- equal-weight BTC/ETH/SOL buy-and-hold: +21.44%
- maximum drawdown: 1.03%
- six completed trades
- 14 ledger executions

This single period shows lower drawdown but substantial benchmark underperformance. It is recorded as a smoke sample, not a profitability conclusion; v0.7.0 will evaluate multiple frozen periods and market regimes without selecting only a favorable start date.

## Boundaries

- This release validates historical behavior; it does not prove future profitability.
- Kraken supplies a limited rolling history, and the current strategy remains deliberately simple.
- Simulation state is in memory and resets when the backend restarts or a new start date is selected.
- No AI/LLM trading decision and no live exchange execution are added.
