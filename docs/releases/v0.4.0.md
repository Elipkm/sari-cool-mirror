# v0.4.0 — Weekly Review

## Goal
Make the system useful to review in a few minutes instead of exposing implementation details.

## Delivered
- `GET /api/review/weekly` as one stable review read model.
- Portfolio equity, cash, total return, weekly return and high-water-mark drawdown.
- Current paper positions and system/circuit-breaker state.
- Ten most recent executed or rejected paper decisions with the original strategy thesis.
- Angular dashboard now loads real backend data instead of placeholder values.
- Dashboard remains intentionally one page: money, week, drawdown, positions, risk state and recent activity.

## Proof
`WeeklyReviewEndToEndTest` boots the real Spring application against the migrated H2 database and verifies a fresh €5,000 paper account produces a healthy, internally consistent review. The complete backend E2E suite passed in GitHub Actions before this release workflow was added.

## Deliberately not added
Charts, configurable widgets, authentication, notifications, LLM summaries and live trading. These would add complexity before they provide enough value.

## Safety
This remains paper trading only. The dashboard is observational and cannot bypass the deterministic risk engine.
