# v0.5.0 — Autonomous Paper Loop

## Goal
Run the paper trader unattended and build a real track record before any live-money work.

## Delivered
- Spring scheduling enabled.
- One daily autonomous run at 00:15 UTC.
- BTC, ETH and SOL are scanned sequentially with the existing trend/pullback strategy.
- BUY/EXIT decisions still pass through the deterministic risk engine and existing paper executor.
- HOLD decisions do nothing.
- Every automation run is persisted with start/end time, SUCCESS/PARTIAL/FAILED status and a compact summary.
- `POST /api/automation/run` triggers the exact same loop manually.
- `GET /api/automation/last` exposes the last run for operations and the dashboard.
- Dashboard shows the daily schedule, latest automation status and latest run summary.

## Proof
`AutonomousPaperLoopEndToEndTest` starts the real Spring application, supplies deterministic market history, calls the automation API, proves all three assets are scanned, proves three valid BUY signals pass through paper execution, proves three positions/trades are persisted, and proves the automation-run record can be read back.

## Operating principle
Start the stack and leave it running. The service evaluates once daily; it does not constantly trade or require supervision.

## Safety
This remains paper trading only. No live exchange execution is introduced in this release. The objective from here is evidence: run it long enough to evaluate returns, drawdown, trade frequency and benchmark performance before considering real money.
