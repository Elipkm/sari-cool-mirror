# v0.2.0 — Real Market State

## Goal

Replace the fake bootstrap portfolio with real market-priced, persistent paper account state.

## Achieved

- Kraken public ticker used as the live EUR price source for BTC, ETH and SOL.
- Market prices are behind the small `MarketPriceProvider` interface.
- The backend overrides caller-supplied reference prices with the authoritative market price before risk checks and paper execution.
- Paper cash and asset quantities are persisted in PostgreSQL/H2.
- `/api/portfolio` returns mark-to-market equity, cash and position exposure.
- Existing fees and slippage remain modeled.
- State survives application restarts because account and positions live in the database.
- Live exchange trading is still disabled.

## End-to-end proof

`PaperTradingEndToEndTest` submits a BTC trade with a deliberately wrong reference price, verifies that the backend uses the market provider price instead, executes the paper trade, then reads `/api/portfolio` and verifies persisted cash, BTC exposure and marked-to-market equity.

GitHub Actions runs `mvn -B test`. The release workflow repeats the same proof before creating the `v0.2.0` tag.

## Deliberate limitations

- Milestone v0.2.0 opens BUY positions only. Position exits belong with the first real strategy lifecycle in v0.3.0.
- No LLM, news feed, sentiment engine or live exchange credentials were added.
